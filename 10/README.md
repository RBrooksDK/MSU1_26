<h1 align="center">Lineær transformationer og transformationsmatricer</h1>

I denne session skal vi se, hvordan flere koordinatsystemer anvendes til at forenkle komplekse beregninger i 3D-grafik og spiludvikling. Vi introducerer verdens-, objekt- og kamerakoordinater og deres anvendelser i forskellige sammenhænge. Vi vil også se på lineære transformationer og transformationsmatricer, og hvordan de kan anvendes til at transformere objekter i 3D-rummet. Vi ser også på homogene koordinater og translationer, og hvordan de kan anvendes til at transformere objekter i 3D-rummet.
